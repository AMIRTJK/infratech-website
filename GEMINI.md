# Правила проекта

Единственный источник правил разработки — `AGENTS.md` в корне репозитория.
Прочитай его целиком перед началом работы и следуй ему.

@AGENTS.md

Этот файл — только указатель. Правила в нём не дублируются: актуальной версией всегда считается `AGENTS.md`. Если правила изменились — меняется `AGENTS.md`, а не этот файл.

## Руководства по производительности

- `PERFORMANCE.md` (корень репозитория) — руководство по оптимизации производительности **frontend** (`client`).
- `server/PERFORMANCE.md` — руководство по оптимизации производительности **backend** (`server`).

Перед разработкой frontend прочитай `PERFORMANCE.md`, перед разработкой backend — `server/PERFORMANCE.md`.
Рекомендации из соответствующего руководства обязательны к учёту при проектировании и реализации своей части проекта: write-time-правила применяются сразу при написании кода, measure-time-правила — на выделенном перф-проходе по данным измерений.

При конфликте: явная просьба пользователя → `AGENTS.md` → руководство по производительности → `docs/ARCHITECTURE.md` → существующий код рядом с правкой.
